# Cybersecurity Guide Book

A beginner-to-job-ready cybersecurity guide that follows a 12-step roadmap. Every topic is explained from two sides: how an attacker abuses it, and how a defender (SOC analyst) detects and stops it. Each chapter is readable directly on GitHub as Markdown (copy-paste friendly), with a PDF copy for offline use. Every chapter includes hands-on labs you can run on your own machine.

> Cybersecurity is a journey. Master the fundamentals first, then specialize in Red Team, Blue Team, Cloud Security, Malware Analysis, or Digital Forensics.

**Author:** [ashihh07](https://github.com/ashihh07)

## How to use this repository

1. Read the chapters in order. Each one builds on the last.
2. Do the labs before moving on. Reading alone does not stick.
3. Write up each lab as a short Markdown note: goal, commands, screenshot, what you learned.
4. Use the quiz at the end of each chapter to find your weak spots.

## Ground rule

Only scan, capture or test systems you own or have written permission to test. Use your own VMs, a home lab, or practice platforms such as TryHackMe and Hack The Box.
